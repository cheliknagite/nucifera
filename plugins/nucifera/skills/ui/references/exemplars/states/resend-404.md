# Resend: 404 page (states)

Source: https://resend.com/this-page-does-not-exist-404, observed 2026-10-22 at 390x844, dark.

**The idea:** the error shows the brand mark unfinished: the R logo drawn as a vector path with its anchor points visible, as if open in an editor, so the 404 is made from the brand's own craft.

**Measured:**
- The drawing: SVG 208x209, 13% of the screen; static (no change over 3 s, no SVG animation).
- Heading "404: Not Found" 24/500; "404" in Commit Mono, the rest in ABC Favorit.
- Two lines of help in 14px, one button "Go back home" (16/600, dark raised), then 4 text links (Documentation, Blog, Sitemap, llms.txt).
- 78% of the text in one secondary grey (white at 71%); the heading white at 94%.
- Colour: none (0 saturated colours).
- Motion on load: none (0 animations).
- Everything sits above y 560; the rest of the screen is black.

**Transfer:**
- Build the error or empty drawing from the product's own material (its mark, documents, instruments) shown in an unfinished state.
- One main way out plus 3-4 named alternatives as plain links.
- Name the problem in two short lines, without apology words.
- A state screen can be fully still.

**Do not copy:** the R with handles (Resend's mark); a mono and a display face mixed in one heading; the "llms.txt" link; the copy.

**With nucifera:** `.empty` with a small drawing (about 120-200px) from the subject in `--fg-2` strokes on `--bg-0`; title 22px, two 16px lines, one `.btn--primary` (or the host's native main button) and a short `.rows` list of alternatives.
