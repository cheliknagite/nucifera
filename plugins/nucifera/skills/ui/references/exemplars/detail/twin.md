# Generic twin: detail

How a default AI generator builds the page of one object (a collectible, an extension, a feature post, a car):

- A full-width image or 3D render with a dark gradient overlay and the title on it in white with a text shadow; or a centred icon in a glowing circle.
- A row of 3-4 "stat cards" under it, each an icon, a number and a label ("625K+ installs", "4.9 rating", "Free").
- Tabs as pills with a violet active state.
- A "Features" or "Highlights" section: 6 identical icon cards with emoji (fast, secure, beautiful).
- Specs in a two-column grid of bordered cells: label 12px uppercase grey, value 14px.
- A reviews carousel with avatars and five stars.
- A sticky bottom bar with a gradient "Get it now" button and a glow.
- Every section fades up on scroll.

**Named differences:**

1. **Facts with meaning.** Fragment pairs each attribute with its rarity (3%, 2%, 0.4%); the twin lists attributes without any comparison.
2. **Provenance.** Fragment puts dated ownership history right under the facts; the twin fills the space with marketing sections.
3. **An artifact from the product's world.** Raycast shows the item as a keycap; Linear uses a real crop of its own interface; the twin uses a generic glowing icon or a stock render.
4. **Facts in one line, not a stat grid.** Raycast puts author, installs and type in one row of text; the twin builds a grid of stat cards with icons.
5. **Colour budget.** Exemplars use colour in 0-2 roles (links, one status) and let the object bring its own; the twin puts violet on tabs, buttons, icons and glows.
6. **Data inside the first screen.** Fragment shows 10 data rows above the fold and Linear starts its text there; the twin spends the first screen on the banner image.
